## Kurzfassung

Dieselbe Organisation kann an der API keine Daten hinterlassen und über die Weboberfläche doch. Der Geltungsbereich hängt am Zugang, nicht am Firmennamen.

## Inhalt

Eine ZDR-Vereinbarung deckt nicht automatisch die gesamte Nutzung eines Anbieters ab: Die Konsole, die Consumer-Pläne und die Team- und Enterprise-Oberflächen sind ausgenommen [B-0044-03]. Für Claude Code auf Claude Enterprise gibt es ein eigenes ZDR-Angebot, das gesondert freigeschaltet werden muss [B-0044-03].

Wie fein das geschnitten ist, zeigt ein einzelnes Werkzeug: Claude Code ist von ZDR erfasst, wenn es mit API-Schlüsseln einer kommerziellen Organisation läuft, nicht aber über einen Consumer-Plan; Nutzungsstatistiken aus aktiviertem Metrik-Logging sind auch auf dem erfassten Weg ausgenommen [B-0044-04] [B-0044-03].

Eine pauschale Zusage „wir speichern nichts" wäre demnach falsch, wenn sie sich auf das ganze Produkt bezieht. Praktisch heißt das: Der Weg, auf dem ein Mitarbeiter das Modell tatsächlich benutzt, entscheidet über die Zusage, und dieser Weg ist meist nicht der, über den der Einkauf verhandelt hat [E].

## Prüffrage

Ihre Firma hat ZDR für die API vereinbart. Ein Mitarbeiter arbeitet über
die Weboberfläche desselben Anbieters. Was gilt für seine Eingaben, und
woran liegt das?
