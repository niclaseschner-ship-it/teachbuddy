# H2 — Wird auf meinen Daten trainiert?

## Worum es geht

Die meistgestellte Frage hat eine unbrauchbare Kurzform. Brauchbar wird sie
erst, wenn man sie in vier Teile zerlegt: Wird aufbewahrt, wird verwendet,
wen bindet die Zusage, und wo gilt sie. Die Lektion macht aus einer
Glaubensfrage eine Aktenfrage.

## Aufbau

1. **WE-0198 — Trainingszusage.** Aufbewahrung und Verwendung sind zwei
   Zusagen; dazu eine benannte 30-Tage-Ausnahme.
2. **WE-0199 — Betreiber und Modellhersteller.** Bei weitergereichten
   Modellen muss die Zusage beide binden.
3. **WE-0200 — Zero Data Retention.** Kein Produktzustand, sondern eine zu
   beantragende Vereinbarung je Organisation.
4. **WE-0201 — Geltungsbereich von ZDR.** Gilt je Schnittstelle; Konsole,
   Agenten-Sitzungen und Team-Oberflächen bleiben ausgenommen.

Die Reihenfolge folgt der Verhandlung: erst was zugesagt wird, dann wer
zusagt, dann wie man es festmacht, dann wofür es gilt. WE-0201 ist die
Pointe, weil dort die sauber verhandelte Zusage an der tatsächlichen
Arbeitsweise der Belegschaft vorbeigehen kann.
