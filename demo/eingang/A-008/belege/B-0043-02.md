Wo eine Anfrage tatsächlich verarbeitet wird, ist an die vom Kunden
gewählte Geografie gebunden, kann aber innerhalb dieser Geografie über
mehrere Regionen wandern; das Modell selbst behält zwischen zwei Aufrufen
nichts.

**Warum das folgt:** Die Aussage trennt explizit „wo verarbeitet" von
„was gespeichert" — zwei unterschiedliche Fragen, die H1 beide stellt.
