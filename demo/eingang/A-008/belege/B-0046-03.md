Die Definition verlangt nicht den Trainingsdatensatz selbst, sondern „Data Information": so detaillierte Information über die Trainingsdaten, dass eine fachkundige Person ein im Wesentlichen gleichwertiges System bauen kann.

**Warum das folgt:** F-0046-03 spricht wörtlich von „sufficiently detailed information about the data" und einem „substantially equivalent system", nicht von der Herausgabe der Daten.
