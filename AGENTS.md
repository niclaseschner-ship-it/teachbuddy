# Für Coding-Agenten

Wer TeachBuddy installieren, einrichten, betreiben oder einen eigenen Lernpfad
damit bauen soll: Der ganze Ablauf steht in
[`.claude/skills/teachbuddy/SKILL.md`](.claude/skills/teachbuddy/SKILL.md).
Er gilt für jeden Agenten, nicht nur für Claude Code. Beginne dort mit
Abschnitt 0 (`python start.py --pruefen`).

Wer am Code arbeitet: die vier Regeln in [`CONTRIBUTING.md`](CONTRIBUTING.md),
die Architektur in [`docs/architektur.md`](docs/architektur.md). Tests:
`python -m pytest -q` und `node --test app/tests/`.
