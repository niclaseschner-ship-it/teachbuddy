# Entscheidungen

Hier steht, **was entschieden wurde und warum** — nicht das Soll-Verhalten
(das steht in `../specs/`).

- `offen.md` — was noch zu entscheiden ist, mit Optionen und Empfehlung.
- `E-<n>.md` — eine gefallene Entscheidung je Datei, sobald sie fällt.

Eine Entscheidung wird nicht dadurch getroffen, dass jemand eine plausible
Antwort in eine Spec schreibt. Sie fällt hier, mit Begründung, und die Spec
löst danach ihren OFFEN-Marker auf.
