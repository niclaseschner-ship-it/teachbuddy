# E-3 — Belegprobe über mechanisch geprüfte Marker

**Entschieden am 10.09.2026. Betrifft AUF-8 und alle vier Format-Specs.**

## Entscheidung

Jeder Sinnabschnitt eines erzeugten Artefakts trägt einen **Beleg-Marker**.
Vor der Freigabe löst das System jeden Marker gegen die Bibliothek auf. Ein
nicht auflösbarer Marker oder ein Abschnitt ohne Marker lässt den Auftrag
scheitern.

Kein zweiter Agentenaufruf zur Prüfung.

## Warum

Die Alternative, ein Prüf-Agent liest das Artefakt gegen die
Wissenseinheiten, hat zwei Nachteile, die zusammen den Ausschlag geben:

1. **Der Prüfer ist selbst fehlbar.** Ein Modell, das prüft, ob ein anderes
   Modell erfunden hat, kann übersehen und kann irren. Die mechanische Probe
   irrt nicht: Eine Beleg-ID existiert oder sie existiert nicht.
2. **Er kostet einen Aufruf je Artefakt.** Unter TB-5 sind Aufrufe das
   knappe Gut, nicht Rechenzeit.

Der Preis ist, dass die Format-Agenten sich an eine markierte Ausgabeform
halten müssen. Das ist eine Einschränkung der Freiheit beim Schreiben, aber
sie ist überprüfbar, und genau das ist der Punkt: TB-1 wird damit vom
Vorsatz zur Eigenschaft des Systems.

## Was daraus folgt

- Jedes Format definiert, was bei ihm ein Sinnabschnitt ist (Sprecherzeile,
  Folienpunkt, Frage, Knoten).
- Marker sind **Metadaten, kein Inhalt**. Sie werden vor der Vertonung und
  vor der Anzeige entfernt und erscheinen dem Lernenden nur dort, wo die
  Spec es vorsieht (POD-14).
- Einordnungen (AUF-13) brauchen einen eigenen Marker, sonst kann eine
  zulässige Überleitung nicht von einer Erfindung unterschieden werden.
